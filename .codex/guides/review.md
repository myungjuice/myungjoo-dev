# 리뷰 가이드

## CodeRabbit 리뷰 감시

- PR 생성 직후 CodeRabbit 리뷰 감시를 등록할지 사용자에게 질문한다.
- 사용자가 승인한 경우에만 감시를 시작한다.
- 감시하지 않는 경우에도 사용자가 공유한 CodeRabbit 피드백은 동일한 절차로 처리한다.

## 리뷰 대응 절차

1. 리뷰 내용을 정확성, 회귀 위험, 테스트, i18n, 접근성, 스타일로 분류한다.
2. 각 항목의 수용 여부와 근거를 요약한다.
3. 수정이 필요한 항목은 변경안과 검증 명령을 먼저 제시한다.
4. 사용자 승인 후에만 수정한다.
5. 관련 테스트와 `pnpm lint`, `pnpm format`을 실행하고 결과를 보고한다.
6. 병합은 사용자의 별도 승인 없이는 수행하지 않는다.

## Codex 코드 리뷰

- 코드 변경이 완료되면 필요에 따라 `/review` 또는 동등한 검토 절차를 제안한다.
- 리뷰에서는 요청한 동작, 기존 패턴, 타입 안전성, i18n, 접근성, 테스트 공백, 회귀 가능성을 확인한다.
- 검증 결과와 남은 위험을 분리해 보고한다.
